# EasyZ Business Setup

Windows installer for **EasyZ Business Ecosystem**.

## Download

**[Download EasyZ_Business_Setup.exe (61 MB)](https://github.com/soudy7mpc/EasyZ-Business-Setup/releases/download/v1.0.0/EasyZ_Business_Setup.exe)**

Or open the [latest release](https://github.com/soudy7mpc/EasyZ-Business-Setup/releases/latest).

## Install

1. Download `EasyZ_Business_Setup.exe`
2. Run it and follow the setup wizard
3. Windows may show a SmartScreen warning for unsigned apps - choose *More info -> Run anyway*
